# 📝 MCQ Generator AI

An AI-powered Multiple Choice Question Generator that uses a Large Language Model (LLM) to create educational MCQs based on a selected topic and difficulty level.

## 🚀 Project Overview

MCQ Generator AI helps students and learners quickly generate
multiple-choice questions for practice and revision.

## ✨ Features

- 📚 Enter any topic
- 🔢 Generate 5, 10, or 15 questions
- 📊 Select difficulty
- 🤖 AI-powered question generation
- 🔤 Four multiple-choice options
- ✅ Correct answer
- 💡 Explanation
- 🎯 Interactive quiz interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Hugging Face
- Large Language Model (LLM)
